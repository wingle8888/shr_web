后台管理

登录后可查看数据总览、全球地址统计（世界地图）、上传产品与资料，管理订单、客户与注册用户。

需要独立打开的客户端？

电脑下载 Windows 客户端，手机下载 Android 安装包，安装后点开即可进入后台。

下载客户端 下载 Android 安装包 Windows 启动器

初始密码：shr-admin-2026。登录后可在右上角修改密码（网页后台、Windows 和 Android 客户端通用）。
