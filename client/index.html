商城控制台下载

电脑用 Windows 客户端，手机用 Android 安装包，打开后都是独立窗口进入商城控制台。

Android 安装包

安装后桌面会出现「商城控制台」，点开即可使用（无需先打开浏览器）。

下载 Android 安装包（APK）
  1. 用手机下载 APK
  2. 打开文件，允许“安装未知应用”后完成安装
  3. 点开「商城控制台」输入密码进入（初始：shr-admin-2026，登录后可在右上角修改）

单独文件

商城控制台.apk Android 使用说明.txt

Windows 桌面客户端

下载后双击即可打开商城控制台，像普通软件一样使用（无需先打开浏览器）。

下载客户端（ZIP） 仅下载启动器
  1. 下载 ZIP 并解压到任意文件夹（如桌面）
  2. 双击「安装到桌面.vbs」，桌面会生成快捷方式
  3. 之后双击桌面上的「商城控制台」打开
  4. 输入密码进入（初始：shr-admin-2026，登录后可在右上角修改）
